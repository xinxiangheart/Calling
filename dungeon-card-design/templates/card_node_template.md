# 行动卡节点模板

在 Obsidian Canvas 里新建一张卡片（双击空白处），把下面的模板整段粘贴进去，
再把取值改成你的内容即可。字段标记必须写成 `【字段名】`，脚本靠它切分。

---

## 复制这一段

```
【卡名】烈焰斩
【品级】稀有
【类别】攻击
【效果】造成 3 点伤害；若目标带有「灼烧」，改为造成 5 点伤害。
【变量】伤害:3; 灼烧伤害:5; 冷却:2
【负面】使用后本回合无法再打出攻击牌。
【获取】第三章商店 / 击败「熔岩守卫」掉落
【进化】烈焰斩+ / 烈焰斩++
【设计意图】给前期铺路的稳定输出，让「灼烧」体系有明确的兑现点。
```

---

## 字段规范

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 【卡名】 | 是 | 卡牌显示名。`【进化】` 里的名字靠它来做匹配。 |
| 【品级】 | 是 | 稀有度，例如 `普通` / `稀有` / `史诗` / `传说`。 |
| 【类别】 | 是 | 例如 `攻击` / `技能` / `能力` / `诅咒`。 |
| 【效果】 | 是 | 卡牌的结算描述，写清楚数值和触发条件。 |
| 【变量】 | 否 | `键:值` 形式，多个用 `;` 分隔，例如 `伤害:3; 冷却:2`。 |
| 【负面】 | 否 | 代价/副作用。没有就写 `无`。 |
| 【获取】 | 否 | 出处：商店、事件、掉落、初始牌组等。 |
| 【进化】 | 否 | 进化目标卡名，多个用 `/` 或 `;` 分隔。 |
| 【设计意图】 | 否 | 这张卡在整体卡组里承担什么职责，方便复盘时对照。 |

## 写法约定

- 一个字段占一行；`【` 必须紧跟在行首或上一字段内容之后，不要放在句子中间。
- 字段名必须和上表完全一致（含中文标点），脚本才能识别。
- `【变量】` 的分隔符支持 `;` `；` 和换行，`键:值` 的冒号支持 `:` `：` `=`。
- `【进化】` 的目标如果在本画布中找不到同名节点，脚本会在日志里给出告警。
- 想换行继续写同一个字段，直接换行即可，直到出现下一个 `【` 才会结束该字段。
- 节点只能用 `text` 类型（文字卡片）；`group` / `file` / `link` 节点会被导出但不参与字段解析。

## 连线即关系

画布上的连线会被导成 `edges`，并在卡片上生成 `outgoing` / `incoming` 与 `forest` 树结构。
建议：

- 连线 label 写关系类型，例如 `进化` / `解锁` / `替代` / `前置`。
- 从弱到强、从左到右摆放，`forest` 会自动把没有入边的卡片当成树根。
