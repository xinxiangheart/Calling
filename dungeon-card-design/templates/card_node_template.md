# 行动卡节点模板

在 Obsidian Canvas 里新建一张卡片（双击空白处），把下面的模板整段粘贴进去，
再把取值改成你的内容即可。字段标记必须写成 `【字段名】`，脚本靠它切分。

---

## 复制这一段

```
【卡名】重击
【品级】普通
【类别】攻击
【效果】造成 {伤害} 点伤害
【变量】伤害_Lv1 = 2; 伤害_Lv2 = 3; 伤害_Lv3 = 4
【获取】初始 / 普通怪掉落
【设计意图】基础单次高伤卡。
```

---

## 字段规范

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 【卡名】 | 是 | 卡牌显示名。 |
| 【品级】 | 是 | 稀有度，例如 `普通` / `稀有` / `史诗` / `传说`。 |
| 【类别】 | 是 | 例如 `攻击` / `技能` / `能力` / `诅咒`。 |
| 【效果】 | 是 | 卡牌的结算描述，写清楚数值和触发条件。代价、副作用也写在这里。 |
| 【变量】 | 否 | `键 = 值` 形式，多个用 `;` 分隔，也可以分多行写。 |
| 【获取】 | 否 | 出处：商店、事件、掉落、初始牌组等。 |
| 【设计意图】 | 否 | 这张卡在整体卡组里承担什么职责，方便复盘时对照。 |

### 已取消的字段

| 旧字段 | 现在怎么写 |
| --- | --- |
| ~~【负面】~~ | 代价直接写进【效果】，数值用 `{变量}` 表达。 |
| ~~【进化】~~ | 用画布连线表达，见下面「连线即关系」。 |

老画布里残留的这两行不会被报错，但也不会进导出结果（原文仍保留在卡片的 `raw_text` 里，
需要时能翻回去）。

## 写法约定

- 一个字段占一行；`【` 必须紧跟在行首或上一字段内容之后，不要放在句子中间。
- 字段名必须和上表完全一致（含中文标点），脚本才能识别。
- 【效果】里用 `{变量名}` 引用变量，例如 `造成 {伤害} 点伤害`。
- 变量名的 `_LvN` 后缀表示只在该等级生效（如 `伤害_Lv1`）；不带后缀的各等级共用。
- 【变量】的分隔符支持 `;` `；` 和换行，键值分隔支持 `=` `:` `：`。
- 【变量】可以写成多行，多行按出现顺序合并，不会被后面的行覆盖。
- 想换行继续写同一个字段，直接换行即可，直到出现下一个 `【` 才会结束该字段。
- 节点只能用 `text` 类型（文字卡片）；`group` / `file` / `link` 节点会被导出但不参与字段解析。

## 连线即关系

画布上的连线会被导成 `edges`，并在卡片上生成 `outgoing` / `incoming` 与 `forest` 树结构。
**进化关系完全由连线表达**，不再有对应的文字字段。

建议：

- 连线 label 写关系类型，例如 `进化` / `解锁` / `替代` / `前置`。
- 从弱到强、从左到右摆放，`forest` 会自动把没有入边的卡片当成树根。

合成规则（运行时）：

- 两张同名同品级 → 合成一张高一级的卡。
- 一张卡有多条出线时，合成时弹出选择；只有一条则直接走；零条则不能合成。
